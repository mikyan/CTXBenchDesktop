# CTXBench Desktop v0.1.8 — 修复用例库启动失败

## 下载 / Downloads

1. [Windows x64 安装程序](https://github.com/mikyan/CTXBenchDesktop/releases/download/v0.1.8/CTXBench-Desktop_0.1.8_x64-setup.exe)
2. [配套四镜像单文件 ZIP](https://github.com/mikyan/CTXBenchDesktop/releases/download/v0.1.8/ctxbench-images-v0.1.8-linux-amd64.zip)

两个文件分别用于更新桌面程序和本地评测服务。镜像 ZIP 不需要解压，在 **设置 → 应用镜像** 中直接选择导入。GitHub 自动提供的 Source code ZIP 不是镜像包。镜像流水线完成后，配套 ZIP 会自动附加到本 Release。

## 修复内容

- **启动即报 10MB 错误**：官方 CTXBench 中存在两条超过 10MB 的用例。旧版在打开页面、自动载入已导入数据时，错误地使用了手工编辑的大小限制，导致整个列表失败。本版完整迁移已验证的原始数据，不裁剪隐藏测试、参考修复或其他评分材料。
- **无法创建评测用例**：独立创建不再依赖已有用例列表加载成功。即使列表异常，仍可打开表单；评测服务正常响应时可以保存，不必先创建评测集。
- **局部数据异常隔离**：某份旧数据缺失或校验失败时，仅列出对应评测集及恢复提示，不隐藏其他可用用例。失败迁移整体回滚，修复源数据后可点 **刷新** 重试，不产生半套用例。
- **更清楚的状态提示**：中英文界面区分加载中、加载失败和真正空库；刷新成功后清除旧错误。手工保存定义改按 UTF-8 JSON 实际字节计量，上限 32 MiB。

## 升级

**必须同时更新桌面端和应用镜像；只更新安装程序不能消除旧服务中的 10MB 限制。**

1. 如有实验正在运行，先暂停并等待当前阶段结束，再通过软件安全停止评测服务。
2. 安装 v0.1.8 桌面程序，在 **设置 → 应用镜像** 导入本版 ZIP。
3. 保持原 WSL 发行版和数据目录不变，启动评测服务，再打开 **评测用例** 或点 **刷新**。

无需删除、清空或重新下载官方数据；历史实验、快照和评分结果保留。内存中的模型凭据在服务重启后需要重新填写。安装包仍未签名；镜像包仅包含四个应用镜像，不包含官方数据文件、全部项目镜像或代码仓库。

## 已验证范围

- 前端回归、生产构建以及后端回归通过。后端 Windows 共 263 项，其中 261 项通过、2 项符号链接权限相关测试跳过。
- 中英文交互覆盖列表失败时创建并保存用例、局部导入警告、刷新恢复和空库提示，并保留编辑冲突、组合评测集和冻结快照检查。

- 原始数据只读挂载，校验哈希未改变；没有重启生产服务或调用模型。此验收是用例库载入验证，不代表跑完官方全集模型评测或新增知识库效果结论。

## English

v0.1.8 fixes library startup failing with “A case definition must not exceed 10 MB” when existing official CTXBench imports contain large grading rows. Verified imports migrate intact; manual saves use a 32 MiB UTF-8 JSON quota. A broken import produces a nonblocking per-dataset warning with atomic rollback, while unrelated cases and independent creation remain available.

Update **both** the Windows desktop and matching application-image ZIP while preserving the existing WSL distribution and data directory. Do not delete or re-download the dataset to work around this bug. The installer remains unsigned, and datasets/project images are separate downloads.

Verification includes bilingual interactions, automated regressions, and isolated Docker import of all 138 locally available official CTXBench rows, including two over 10 MB. Source hashes and the largest case's frozen grading data were preserved. No Provider calls or full-suite benchmark execution were performed for this patch.
