# CTXBench Desktop v0.1.5 — 工作台体验重构

## 下载 / Downloads

首次安装或升级需要两个同版本文件（GitHub 自动生成的 Source code ZIP 不是镜像包）：

1. [Windows x64 安装程序](https://github.com/mikyan/CTXBenchDesktop/releases/download/v0.1.5/CTXBench-Desktop_0.1.5_x64-setup.exe)
2. [四个应用镜像的单文件离线 ZIP](https://github.com/mikyan/CTXBenchDesktop/releases/download/v0.1.5/ctxbench-images-v0.1.5-linux-amd64.zip)

镜像 ZIP 无需解压，包含 Worker、Pi Agent、出口代理、官方测试工具及校验清单，不包含密钥、评测集、任务基线仓库或全部任务测试镜像。标准评测集请在“评测集 → 标准集下载”查看固定官方快照，也可阅读[下载指引](https://github.com/mikyan/CTXBenchDesktop/blob/v0.1.5/docs/standard-datasets.md)。数据本体未重新分发到本 Release。

## 本次更新

- **设置分层**：按基础连接、安装交付、公司适配组织六类配置——运行环境、模型凭据、应用镜像、公司方案、镜像适配、资源迁移。切换分类保留未保存输入；密钥不持久化为浏览器草稿。
- **按任务组织页面**：评测集成为独立入口，支持已导入数据浏览、标准下载和用例自检。实验计划、结果证据、Token 预算分别查看；知识库与约束的列表和生成/挖掘队列分开。
- **三步实验向导**：任务与对照 → 模型与执行 → 检查并创建。前进/返回保留配置；启动命令、多步 Prompt 等高级项按需展开，未删除原有能力。
- **可读性与交互**：提高文字对比度和常用字号，统一间距、表单密度和焦点状态，验证中英文及最小桌面尺寸；先显示运行结论，再展开原始参数与校验标识。
- **状态纠错**：概览区分真实已评分次数与全量验收；当前实验不再混入其他已暂停实验的任务；旧 Worker 接口不支持公司配置时给出明确升级指引。
- **验收与稳定性**：补充真实 CTXBench 验收入口、独立评分对照测试与复现文档；修复 Windows 临时 Git 文件短暂占用造成的测试清理抖动，持续错误仍会上报。

## 真实 CTXBench 测试结果

MiMo v2.5，两个官方任务、无知识库 / Skill 知识库两个分支，各重复两次：**7 次通过官方测试，1 次 Agent 达到 45 分钟超时，没有功能评分**。超时后容器回收，队列正常继续；没有重跑覆盖、改变单侧参数或放宽测试。

两个知识库各生成一次并冻结复用；四组执行参数绑定核对通过，其中 **3 组有完整双侧评分**。两个任务的空补丁负对照均失败、参考补丁正对照均通过；对照只在评分器执行，不调用模型。

**这不是官方 138 任务全量验收，也不是 8/8 全部通过。** 严格完整功能验收标记仍为失败；不能用此样本声称知识库总体提升。本轮没有追加 SWE-SHIELD 的真实评审。详见[完整验收记录](https://github.com/mikyan/CTXBenchDesktop/blob/v0.1.5/docs/ctx-live-acceptance.md)。

本地回归：前端 113 项通过；Linux Worker 144 项通过；Windows Worker 142 项通过、2 项符号链接权限相关测试跳过；脚本 44 项通过、4 项真实镜像往返测试留给发布流水线。原生测试、构建和真实 Docker 的模拟 Provider 集成另行通过。远端 CI 与镜像资产验证状态以本 Release 的发布验收信息为准。

## 升级与边界

**桌面和 Worker 请一起升级。** 暂停实验，等待当前阶段结束，在“设置 → 运行环境”安全停止工作节点；安装新版桌面，在“设置 → 应用镜像 → 安装或构建 → 离线安装”导入同版本 ZIP，再返回“运行环境”显式启动。旧版对应“基础设施”入口。保留原数据目录，不要删除 WSL 数据卷。

Windows x64；所选 WSL2 发行版须具备 Python 3.10+、Docker Engine 和 Compose。安装程序未签名，请遵守公司的安全策略，不要关闭安全防护。

完整离线资源迁移目前只覆盖自定义评测集及预构建测试镜像，不覆盖官方 SWE/CTX 动态环境的完整脱网迁移。镜像依赖及历史层仍需自行审查许可和敏感信息；公司方案中的代理域名不会自动热应用。自动更新、代码签名和完整实验数据库迁移不在本版范围内。

## English

v0.1.5 introduces six focused Settings categories, a first-class dataset library, separate experiment/results/budget views, a three-step experiment wizard, readable typography and contrast, and clearer errors and evidence. It preserves passive context discovery, paired-run invariants, evaluator isolation and credential handling.

Real MiMo v2.5 CTXBench smoke acceptance covered two official tasks × two arms × two repeats: **7 official-test passes, 1 Agent timeout without a functional grade**. Frozen contexts were generated once and reused; all four evaluator-only positive/negative controls behaved correctly. Only three pairs have complete grades. This is neither full 138-task certification nor an 8/8 successful acceptance.

Download both the Windows installer and the matching one-file offline image ZIP. Upgrade desktop and Worker together, preserving the data directory. The ZIP contains four application images, not standard datasets or their full runtime dependencies. WSL2, Python 3.10+, Docker Engine and Compose are prerequisites. The installer is unsigned. Consult release verification below before deploying a prerelease.
