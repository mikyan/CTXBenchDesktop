## 新增与修复

- **删除用例、评测集和实验结果**：先在弹窗中展示影响范围，再确认删除；活动实验受到保护。删除某轮结果时删除完整对照组，统计与导出标注样本删除情况。此操作不清理镜像、证据文件或冻结快照，没有一键撤销功能，请先备份。
- **应用内中英文帮助**：常见操作与术语直接在应用内说明，不再从中文帮助跳到英文仓库首页。
- **镜像制作更清晰**：可以从已安装镜像中选择基础镜像；文件导入后明确显示状态。允许沿用已有工具镜像、安装命令留空继续适配。
- **修复非 root 运行权限**：镜像向导在安装后整理默认 HOME 的所有权，并以运行用户检查可写性，避免 OpenCode 等工具因 root 创建的缓存目录而启动失败。自定义 HOME/XDG 路径仍需自行配置权限；不会自动改造已有镜像。
- **用例与实验向导**：切换步骤回到新步骤标题；解释冻结知识库匹配条件并支持就地导入、保留草稿；最终确认展示各用例实际采用的 Agent 镜像，避免与实验默认 Pi 镜像混淆。
- **本地 Git 基线兼容**：修复 Windows/WSL 跨所有者仓库在准备或资源导出时的 Git 拒绝。例外只作用于明确选择的本地仓库和本次命令，不写全局信任配置、不修改仓库权限。
- **结果日志可读可查**：合法的复合运行编号不再被日志接口误拒绝；确定性请求错误不再显示为持续断线重连。评分证据正文不再被压成一行，支持多行阅读和独立滚动。
- **资源导出入口**：明确可以直接选择独立用例，也可选择评测集，不必先组合成集合。

## 升级注意

1. 有实验执行时，先暂停并等待当前阶段结束，再通过应用安全停止评测服务。
2. 安装本版桌面程序，导入配套四镜像 ZIP，保持原 WSL 发行版及数据目录。
3. 启动服务，按需重新配置仅保留在运行时的模型凭据。
4. 既有自定义镜像不会自动获得 HOME 权限修复；可在镜像向导中以原镜像为基础、安装命令留空重新适配，并在新用例版本中选择新镜像。

保留旧实验快照。若准备好的旧实验提示冻结实现已变化，请使用匹配旧环境完成，或在新版重新准备新实验；不要改写旧快照绕过校验。

安装程序仍未签名。四镜像 ZIP 不包含官方评测数据、全部项目镜像、个人 OpenCode 镜像或 API 密钥。删除记录不等于释放全部磁盘空间；详细边界见[数据删除说明](https://github.com/mikyan/CTXBenchDesktop/blob/v0.1.10/docs/data-deletion.md)。

## English

v0.1.10 adds impact-confirmed deletion of cases, sets, experiments and complete comparison groups; bilingual in-app help; installed-image selection; clearer upload, frozen-context and actual-Agent-image guidance; command-scoped local Git ownership compatibility; and readable completed-run logs. Image recipes now repair and check the fixed default HOME after installation without changing the non-root runtime or following external symlinks.

Update **both** the desktop and matching image ZIP. Preserve existing data and frozen experiments; adapt existing custom images separately. Deleting records is not disk cleanup and has no one-click undo. The installer is unsigned, and task datasets/images and credentials remain separate.

Verification: 221 frontend tests; 310 passing worker tests with 3 Windows platform skips; bilingual UI and isolated Docker checks. A real OpenCode + MiMo v2.5 custom backend pair passed 9/9 independent tests per arm. This is one manually provided-context pair, not official-dataset coverage or evidence of a statistically stable knowledge benefit. Portable resources passed local export and pre-import validation, not a second-machine run.
