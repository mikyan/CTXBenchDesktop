## 本次更新

- **从 Windows 直接选择评测集文件**：选择 Parquet／JSON／JSONL，检查预览并确认导入；不用手工复制到 WSL、Docker 或 root 管理目录。错误会区分不完整题目、参考修复／测试材料、无效文件和旧服务版本。
- **按需安装官方项目镜像**：评测集卡片新增镜像安装入口，按用例筛选、去重，展示 Docker 层下载／解压日志，支持取消、重试和恢复查看。默认仅选择首个用例，避免意外下载整个评测集。
- **可选公司 Docker 仓库**：支持镜像名前缀映射、元数据可用性检查、缺失／认证／网络故障区分，以及只选择镜像可用的用例。安装后可将所选用例和公司配置带入新实验。Docker Hub 可访问时不必启用映射；自定义用例可直接使用公司镜像地址。
- **可复用的项目构建环境**：在模型调用前，以干净基线和项目依赖准备带 Pi 的环境，让知识库构建和编码 Agent 能构建／测试项目。同一环境按内容冻结、跨配对和重复复用；隐藏测试与参考补丁仍留在独立评分端。
- **统一镜像解析**：公司配置贯穿安装、独立知识库准备和实验执行；官方评分器使用传入的固定镜像，不在内部重新拉公共地址。缺少后续用例镜像时先停止准备，不提前消耗模型额度。旧评分器给出明确升级指引。
- **弹窗、镜像选择与维护恢复**：放弃编辑、覆盖草稿、删除编排内容、停止服务等改用居中确认框；长表单保持关闭按钮可见，失败信息进入视线。自定义测试镜像支持本机列表和手填；镜像更新前显示活动容器与处理入口，不自动强停其他部署。
- **官方 SWE 兼容性修复**：固定评分器版本与所导入的原始 Verified 快照兼容，保留官方测试选择与评分规则。

## 升级与限制

请同步更新桌面端与四个应用镜像。先暂停实验并等待当前阶段结束，按软件中的活动检查安全停止本地评测服务，再安装桌面并导入同版本镜像 ZIP，最后重新启动。保留原数据目录，不删除 WSL 数据卷。运行时输入的凭据需要重新填写。

- 项目镜像“已安装”不代表依赖或测试已验证成功；CTX 仍会进行基线依赖准备。
- 公司镜像映射不重写 npm／pip／Maven 源或任意 Dockerfile。认证可先在所选 WSL 中 `docker login`、`docker pull`，软件随后复用同一引擎中的本机镜像；主机登录凭据不会自动共享进服务容器。
- 镜像及已准备环境默认缓存复用，代码工作目录、日志和知识库也保留。**本版没有自动存储回收或图形化镜像清理管理**。
- 官方动态环境的完整脱网资源包、代码签名和自动更新仍不在本版范围。Windows 安装程序未签名，请遵守公司安全策略。

## English

v0.1.6 adds native local dataset file import, on-demand official project image downloads, optional company registry mappings and metadata availability checks, subset-to-experiment handoff, reusable Pi project build environments, and safer authoring/maintenance dialogs. Installation, standalone knowledge preparation and evaluation share image resolution while preserving passive context discovery, paired-run invariants and evaluator-only data boundaries.

Upgrade the desktop and all four application images together, preserving your data directory. Project images and datasets are separate; reachable Docker Hub installations can download selected project images directly. Custom datasets can use company images. Package-manager source configuration and storage cleanup management are not included.

Validation covers automated regressions, bilingual UI interactions, real Docker registry checks and one official reference-grading task per suite. It is not full SWE/CTX Provider acceptance. The installer is unsigned; follow your organization's security requirements.
