## 本次更新

- **独立用例库**：先创建和编辑评测用例，再从已有用例组合、编辑评测集；单个用例也可直接生成知识库或开始实验。启动时冻结用例版本、基线、Prompt、测试及成员关系，后续编辑不改变旧任务、重试或结果。
- **自定义编码 Agent**：用例中单独配置镜像和启动命令，不要求 Pi；支持 Shell 或 JSON 参数数组、多步 Prompt 编排和运行时白名单环境变量。Agent 编码与测试判分保持独立，知识库生成及约束角色仍沿用实验配置。
- **Token 未知不阻断测试**：自定义命令缺少用量时显示未知，不伪装为零，不影响执行、判分、通过率或配对比较。自定义阶段跳过共享 Token 预算预留／扣账／耗尽检查；可统计角色继续受原有预算保护。时长、CPU、内存和网络限制仍有效。
- **镜像下载与制作向导**：“设置 → 镜像适配”可下载公司仓库完整镜像地址，查看日志、取消和重试。四步引导选择基础镜像、安装依赖、上传非敏感默认配置、确认构建；不覆盖原镜像。测试和 Agent 镜像字段提供下载快捷入口。
- **官方镜像精确地址**：SWE／CTX 项目镜像安装器支持逐镜像填写完整公司地址，或粘贴单条 `docker pull …`；保存后供未来安装、知识库准备和评测使用，已冻结任务保持原地址。
- **可替换的 CI 门禁**：自定义用例可将候选代码提交到 GitHub 专用评测分支，校验指定工作流／门禁，并读取 JUnit 测试数量。提供 Maven 示例和公司 HTTP 网关适配协议，平台凭据不传给编码 Agent。原本的 Docker 本地测试与官方评分流程保留。
- **中英文说明与交互**：补充镜像用途、Prompt 传递、目录权限、内网依赖源、配置和安全限制说明；保留旧版草稿、manifest 导入和历史结果。

## 升级与限制

**桌面端与应用镜像必须一起更新。** 先暂停实验、等待当前阶段结束，按软件的活动检查安全停止服务，再安装新版桌面并导入同版本镜像 ZIP，最后启动。保留原数据目录，不删除 WSL 数据卷；运行时内存凭据重启后需重新填写。

- 自定义镜像至少需要自己的非交互式 Agent、`python3`、`git`、`/bin/sh`，可供 UID 10001 使用。镜像入口由命令适配器替换，配置和依赖不要只放在会被基线覆盖的 `/workspace`。
- 任意 CLI 的真实模型和 Token 上限无法由工具确认或强制；在 Agent／Provider 侧限制消费。共享预算显示的用量不包含自定义命令，并不代表其没有消耗。
- 自定义命令目前只替换编码角色，知识库生成和约束角色使用原有适配器。正式配对固定命令、镜像和适配器；升级后若恢复任务遇到适配器哈希不符，需恢复匹配服务或新建实验，不会混用执行实现。
- 私有仓库认证目前在选定 WSL 中 `docker login`、`docker pull`，回软件刷新。主机凭据不会自动共享到服务容器。构建向导不支持通过 Dockerfile 或上传文件保存密钥；私有包构建期认证请使用公司安全构建流程。
- 本地判分仍离线，所需测试依赖必须提前备齐。镜像构建成功不等于项目测试可用。镜像和实验数据继续缓存保留，本版不新增自动清理、官方动态环境完整离线打包或代码签名。

## English

v0.1.7 adds editable evaluation cases, composed datasets, immutable execution snapshots, custom coding images/commands without Pi, remote image pulls, guided dependency/default-configuration recipes, per-image official registry addresses, and optional GitHub CI grading with a replaceable company-platform adapter.

Missing custom CLI token usage does not block execution or change grades. These stages bypass shared token accounting; metered roles retain budget protection. Use provider-side spending limits. This coding-only override requires Python 3, Git and a Shell, runs unprivileged in Docker, and keeps grading inputs isolated.

Update the desktop and application-image ZIP together while preserving existing data. The installer is unsigned. Datasets and project images are separate downloads. Validation includes automated/bilingual checks, real non-Pi Docker positive/negative controls and earlier Pi/MiMo/GitHub CI acceptance, not full official-suite or knowledge-effect evaluation.
