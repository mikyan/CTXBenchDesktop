## 必须保留的边界

1. 这是可用的单机研究工作台，不是已认证的企业级、多租户或公网服务。Worker 有 Docker-host 权限；只有可信本地用户应访问。
2. 本次真实运行是代表性 smoke/repeat 验证，不是 138 条 AgentBench / 500 条 SWE-bench Verified 的全量跑分，也不证明知识库一定提升效果。单任务重复不提供总体置信区间。
3. SWE-Shield 是带来源证据的银级兼容实现，不是论文完整复现。Embedding 聚类、完整 DesignHunter 流程、人工金级审校/一致性标注、金补丁语义关联不在当前运行链中。详见 [评测方法](evaluation.md)。
4. 历史采集受 GitHub API 配额和有限窗口约束。旧版冻结包保留原始 provenance，不会被偷偷重新标成新版历史过滤算法。手工材料的基线/任务盲声明不能从文件内容自动证明。
5. 内网迁移需要准备内部 Provider/Agent 适配镜像、API 域名白名单、数据集实例镜像、仓库和数据。应用镜像导出不等于整个 benchmark 环境已离线齐备。交互式网页登录/SSO 不在 API-key 首版范围。
6. 尚未完成发行签名、自动更新、全新无开发工具 Windows 机器安装验收，以及大规模长时间/真实磁盘满/物理断电压力验证。下文的进程强杀、合成容量及模拟 ENOSPC 验证不能替代这些验收。结果目录和固定镜像为审计而保留，当前不会自动清理；备份前应暂停并停止 Worker，连同 SQLite WAL/SHM 一并保存整个数据目录。
7. 费用来自 Provider/Pi 上报，并非实际账单；Token Plan 上报零费用不能解释为免费。一次性知识库和评审用量保存在各自证据中，总览的平均费用只汇总求解阶段。

以上边界不能用“所有测试通过”替代。未来扩展应从明确的验收项出发，不应把未连接的研究辅助函数或示例界面当成已交付功能。

## 提交后继续补齐（起点 `63997db`）

- 独立知识库生成/约束挖掘也有持久化暂停、恢复、取消、重试；操作修订号防止旧线程完成时覆盖新控制请求。实验取消后立即重试也不会丢失新请求。
- 完成的求解/生成/挖掘/评审阶段保存关键文件哈希；已完成证据被修改时拒绝静默复用。旧记录明确视为 `legacy-unverified`，不会因升级凭空获得新完整性证明。评分 checkpoint 绑定数据集、任务、补丁、harness 和资源；损坏或错配时保留旧摘要并只重新评分，不重新付费求解。
- 冻结数据集校验、知识库完整文件清单与符号链接防护；损坏包在页面显示为无效。运行时凭据若出现在待发布知识库或评审输出中会被拒绝。
- 全量规模只读预检、各角色 Token 额度合计、低空间阶段准入保护。额度不是账单或硬性总上限，缓存尚未扣除，进行中的 Provider 请求可能超出阶段限制。
- 轮询快照不再携带完整评分/投票正文，详情单独读取；结果和知识库分页；约束聚合与配对统计使用索引。完整 JSON 导出仍保留证据。
- 崩溃验收发现并修复旧 Agent 容器只杀停未删除的问题；重启时清理本数据库拥有的未完成阶段，包括已暂停操作的遗留容器。不会清理其他 Worker 或用户容器。
