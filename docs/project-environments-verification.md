## 已确认的上游兼容性问题

SymPy 同一基线的 `sympy/core/tests/test_args.py` 在新环境与未经清理的原始实例镜像中均为：617 项通过、58 项跳过、19 项预期失败、33 项异常。异常包含 Python 3.9 对 `collections.MutableMapping` 等旧导入产生的弃用警告，被旧测试框架当成异常。

因此，不能声称整个 SWE 用例的所有可见测试已通过，也不能把这些失败归因于新增的依赖准备。没有通过修改基线、忽略失败或全局屏蔽警告来制造通过结果。正式评分仍应使用官方指定的测试选择与评分协议；若要改变项目依赖，应新建并冻结环境版本后重新跑完整配对。
